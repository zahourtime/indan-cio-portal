# InDan // Аналитический ИИ-портал для CIO

Локальный интерактивный MVP аналитического консалтингового портала в духе Gartner.

> **Сценарий:** «Криптокошельки для банка: клиентский контур и собственные активы казначейства».  
> **Роль:** Директор по информационным технологиям (CIO).  
> **Стиль интерфейса:** Черно-белый минимализм с эффектом жидкого стекла (`Liquid Glass / Frosted Glassmorphism`).

---

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка окружения (опционально)
Для работы живого генеративного AI Copilot скопируйте `.env.example` в `.env` и при необходимости укажите ключ Gemini:
```bash
cp .env.example .env
```

### 3. Запуск проекта
Запуск как фронтенда (Vite), так и встроенного сервера телеметрии (Node.js API):
```bash
npm run dev:all
```

* **Интерфейс портала:** [http://localhost:5173/](http://localhost:5173/)
* **Сервер данных и телеметрии (SSE / REST API):** [http://localhost:3001/](http://localhost:3001/)

Либо запуск по отдельности:
* `npm run dev` — только фронтенд
* `npm run server` — только backend-сервер реального времени

## 🖥 Структура экранов и интерактивность

1. **Главная (Обзор решений / Investment Strategy Matrix):**
   * Три колонки: **Купить** (зеленый индикатор), **Подождать** (желтый), **Избегать** (красный);
   * Карточки поставщиков и технологий с обоснованием «почему»;
   * Клик по карточке поставщика $\to$ мгновенный переход в его детальное досье;
   * Горизонтальная плашка **«Сигналы квартала»** с индикаторами рыночных и регуляторных изменений.

2. **Кривая зрелости (Hype Cycle):**
   * Интерактивная кривая Gartner на 5 фаз (*Запуск $\to$ Пик ожиданий $\to$ Впадина $\to$ Склон прояснения $\to$ Плато*);
   * 8 светящихся точек технологий с тултипами при наведении (риски, горизонт внедрения, ссылки на спецификации BIP/EIP/NIST);
   * Нижняя плиточная сетка с характеристиками технологий.

3. **Квадрант поставщиков (Magic Quadrant 2x2):**
   * Координатная сетка: *Способность исполнить (1..5)* vs *Полнота видения (1..5)*;
   * 4 зоны: **Лидеры** (Fireblocks, BitGo, Coinbase Custody), **Претенденты** (Anchorage, Ledger Enterprise), **Провидцы** (Fordefi, Dfns), **Нишевые** (Komainu);
   * Правая панель со списком игроков: при наведении подсвечивается точка на графике, по клику — переход в досье.

4. **Досье поставщика (Vendor Intelligence Dossier):**
   * Полный разбор выбранного вендора (Fireblocks, BitGo, Coinbase Custody и др.);
   * Модель владения ключом (например, `2-of-3 MPC`), мини-радар квадранта;
   * Двухколоночный факт-чекинг: *«Что заявляет компания»* vs *«Что подтверждено ссылкой и аудитом (SOC 2 Type II, OCC Charter)»*;
   * Журнал инцидентов и безопасности.

5. **Источники данных (Data Provenance):**
   * Реестр открытых источников: официальная документация, регуляторы (MiCA, SEC, OCC), открытые стандарты, деловая пресса;
   * Список исключений: что портал принципиально не использует (платные отчеты за paywall, анонимные слухи, невалидированный маркетинг).

6. **AI Copilot (Парящий виджет и модальное окно):**
   * Вызывается кнопкой в правом нижнем углу экрана или пунктом бокового меню;
   * Анимированная визуализация звуковой волны CIO Voice Sync;
   * Слайдеры настройки риск-аппетита (*Conservative / Moderate / Aggressive*) и глубины комплаенса;
   * Переключатели проверки MiCA и SOC 2 аудита;
   * Генерация одностраничной служебной записки для инвестиционного комитета банка (*Strategic Decision: Split-Custody Model*) с кнопкой копирования и экспорта в PDF.
